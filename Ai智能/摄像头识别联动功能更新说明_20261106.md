# 摄像头识别联动功能更新说明

> 更新日期：2026-11-06
> 对象文件：`examples/esp32s3/ai_voice_display_lcd/main.cpp`
> 项目：S3小智 ai_vox-1.3.2（ESP32-S3 模拟种植演示板，A 板主控）

---

## 一、本次新增功能总览

本次在 `main.cpp` 新增了一整套 **「摄像头识别 → 多执行器联动」** 能力，核心特点是：

- **判断词口述配置**：识别什么关键词触发，随时用语音说，不写死。
- **执行器口述配置**：满足条件后做什么（舵机 1/2/3 任意角度 + 电机 1/2 正反转调速 + RGB 灯 1~8 颜色），也能口述随时改。
- **多执行器同时动作**：一条规则可同时控制任意组合的舵机 + 电机 + RGB 灯。
- **生长阶段归类**：口述"开花期/结果期/幼苗期"等阶段词，自动匹配对应特征词（开花/果实/嫩芽……）。
- **特征词也可口述改**：阶段词对应的特征词列表，用嘴说就能整句替换。
- **播报语可配**：命中后播报什么话也能口述指定。

## 二、三个新增 MCP 工具

### 1. `self.vision.link` —— 设置联动规则

设置一条"识别到关键词 → 执行一组动作"的规则。

**参数：**
| 参数 | 类型 | 说明 |
|---|---|---|
| `keyword` | string | 触发关键词，可用竖线 `\|` 分隔多个（任一命中即触发） |
| `actions` | string | 动作列表（见下方格式） |
| `speak` | string | 命中后播报的话（可选） |

**actions 动作格式（逗号分隔多项，冒号分隔字段）：**

| 口述 | 内部格式 | 含义 |
|---|---|---|
| 舵机1转90度 | `servo1:90` | 舵机1 → 90° |
| 舵机2转45度 | `servo2:45` | 舵机2 → 45° |
| 舵机3转135度 | `servo3:135` | 舵机3 → 135° |
| 电机1正转 | `motor1:forward` | 电机1 正转（默认速度150） |
| 电机1反转速度200 | `motor1:reverse:200` | 电机1 反转，PWM 200 |
| 电机1停 | `motor1:stop` | 电机1 停止 |
| 电机2正转 | `motor2:forward` | 电机2 正转（开关） |
| 电机2反转 | `motor2:reverse` | 电机2 反转 |
| 电机2刹车 | `motor2:brake` | 电机2 刹车 |
| 红灯亮 | `led:red` | 全部 8 颗亮红色 |
| 第1颗灯绿 | `led1:绿` | 第1颗亮绿（led1~led8） |
| 第3颗灯蓝 | `led3:blue` | 第3颗亮蓝 |

> 灯颜色支持：红/绿/蓝/黄/青/紫/白（中英文均可）。`led:色` 全亮，`ledN:色` 单颗。

**用法示例（口述）：**
- "识别到风扇的时候，舵机1转90度"
- "识别到结果期的时候，舵机1转90度舵机2转45度电机1正转"
- "看到香蕉的时候，舵机2转45度，然后说发现香蕉了"
- "识别到结果期的时候，舵机1转90度电机1正转红灯亮"

### 2. `self.vision.stage` —— 口述设置阶段特征词

设置某个生长阶段对应的特征词列表（**整句替换**，覆盖旧的）。

**参数：**
| 参数 | 类型 | 说明 |
|---|---|---|
| `stage` | string | 阶段词（开花期/结果期/幼苗期/成长期/成熟期/枯萎 之一） |
| `features` | string | 特征词列表，竖线 `\|` 分隔 |

**用法示例（口述）：**
- "开花期的特征是 开花 花朵 花苞"
- "结果期对应 结果 果实 结瓜"
- "把枯萎的特征改成 枯黄 蔫了 掉叶子"

### 3. `self.vision.reset` —— 恢复/清空

清空所有联动规则，舵机回 0 度，电机全停。

**用法：** 说"恢复""舵机恢复""恢复初始位置""取消识别联动"。

## 四、核心代码结构（新增/修改位置）

### 数据结构（main.cpp 约 3294 行起）

```cpp
// 一条动作: 舵机 / 电机1 / 电机2 / RGB灯 四选一
struct VisionAct {
  int type;     // 0=舵机, 1=电机1(PWM), 2=电机2(开关), 3=RGB灯
  int index;    // type=0: 舵机编号 1~3; type=3: 灯号 1~8(0=全部8颗)
  int angle;    // type=0: 角度 0~180
  int dir;      // type=1/2: 0=停, 1=正转, 2=反转, 3=刹车(仅电机2)
  int speed;    // type=1: PWM 0~255, -1=用默认150
  int hue;      // type=3: 色相 0~255
  int sat;      // type=3: 饱和度 0~255(0=白)
  bool valid;
};

struct VisionLinkRule {
  char keyword[64];    // 触发关键词('|' 分隔多个)
  char speak[64];      // 命中后播报语
  VisionAct acts[8];   // 动作列表(最多8个)
  int act_count;
  bool active;
};
constexpr int kMaxVisionLinks = 6;
VisionLinkRule g_vision_links[kMaxVisionLinks];
```

### 关键函数

| 函数 | 作用 |
|---|---|
| `VisionLinkMatch(keywords, text)` | 关键词匹配，含阶段词→特征词展开 |
| `VisionParseActions(rule, actions)` | 解析 actions 字符串成动作列表 |
| `VisionExecActs(rule)` | 执行一条规则的全部动作 |
| `VisionLinkCheck(text)` | 识别结果命中检查入口（在 `CamUploadHttp` 解析出 `text` 后调用） |
| `VisionSetStageFeatures(stage, features)` | 口述覆盖阶段特征词 |
| `VisionLinkReset()` | 清空规则 + 执行器复位 |

### 联动触发点

`CamUploadHttp` 函数解析出识别结果文字 `out` 后，在 `return ok;` 前调用：

```cpp
if (ok) {
  const int hit = VisionLinkCheck(out);
  if (hit > 0) {
    printf("[cam] vision link triggered %d rule(s)\n", hit);
  }
}
```

即：**每次摄像头识别返回结果，都自动做一次联动检查**。

## 五、与既有功能的衔接

- **舵机**：复用 `ServoWriteAngle(idx, angle)`（IO12/13/14，LEDC 50Hz）。
- **电机1**：复用 `Motor1Set(dir, speed)`（IO1/IO2，PWM 20kHz 可调速）。
- **电机2**：复用 `Motor2SetDirection(dir)`（IO47/IO48，纯开关）。
- **RGB 灯**：复用 `LedColorFromName`（颜色名→hue/sat）、`g_led_pick_mask` + `g_led_pick_hue[]/sat[]` + `LedShowPickMask()`（IO38，WS2812×8，逐颗独立颜色）。
- **播报**：复用 `MonSpeakNow(text)`（监测系统播报通道，自带"AI 说话中不打断"保护）。
- **识别结果**：复用 `CamUploadHttp` 解析出的 `text` 字段（官方 vision 接口返回的中文描述）。

## 六、内存影响

新增数据结构均为**全局静态变量**（`.bss` 段），不占动态堆、不会泄漏：

- `VisionLinkRule × 6` ≈ 2.0 KB（`VisionAct` 加了 hue/sat 字段，略增）
- `StageMap × 6` ≈ 0.6 KB
- **合计约 2.7 KB**

对 ESP32-S3 N16R8（512KB 内部 SRAM + 8MB PSRAM）而言占比约 0.5%，可忽略。
匹配时的临时缓冲区（`buf[128]`/`fbuf[128]`）都是栈上局部变量，用完即释放。

---

## 七、使用须知

1. **规则/特征词均存内存**：断电/重启后失效，需重新口述设置。
2. **阶段词是固定 6 个**：开花期/结果期/幼苗期/成长期/成熟期/枯萎，特征词可改、阶段名不能新增。
3. **普通判断词精确匹配**：风扇、香蕉等非阶段词，识别文字里须原样出现该词才命中。
4. **验证点**：串口会打印 `[VisionLink] HIT 'xxx' -> N acts` 及各执行器动作日志；识别原文看 `[cam] upload done ok=1 ... result=...`。
